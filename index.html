Frequently Asked Questions

What is ScrapeGraphAI? +
ScrapeGraphAI is an AI-powered web scraping API that lets you extract structured data from any website using natural language prompts. No complex selectors, no brittle scripts. Just describe what you want and get clean JSON back.
How does AI-powered web scraping work? +
You send a URL and a natural language prompt describing the data you need. Our AI models read and understand the page content, then extract exactly the fields you asked for, returned as structured JSON. It handles dynamic content, SPAs, and messy HTML automatically.
Do I need to write CSS selectors or XPath to scrape websites? +
No. ScrapeGraphAI uses large language models to understand page content semantically. You describe what you want in plain English. No selectors, no regex, no DOM traversal. The AI figures out where the data lives.
What data formats does the web scraping API support? +
All responses come back as structured JSON matching your prompt. You can also provide a JSON schema to enforce exact output shapes, perfect for feeding data directly into your pipeline or database.
Is ScrapeGraphAI free to use? +
Yes. The free plan includes 500 API credits, enough to test the API and build a proof of concept. Paid plans start at $20/month with 10,000 credits and scale up from there.
Can ScrapeGraphAI scrape JavaScript-rendered pages and SPAs? +
Yes. ScrapeGraphAI handles JavaScript-heavy pages, single-page applications, and dynamically loaded content out of the box. No need to manage headless browsers yourself.
How fast is the ScrapeGraphAI API? +
Most requests complete in 2-10 seconds depending on page complexity and the amount of data extracted. Frequently requested URLs are cached, so repeat calls come back almost instantly.
Is there an MCP server for AI agents? +
Yes. We provide an official MCP (Model Context Protocol) server so AI agents like Claude, Cursor, and Windsurf can use ScrapeGraphAI as a tool directly. Install it with one command and your agent gets web scraping superpowers.
